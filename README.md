# AI Chatbot Backend 🚀

A lightweight, high-performance asynchronous API backend built with **FastAPI** and **Python 3**. This project serves as a dynamic backend engine for a full-stack AI Chatbot application, utilizing automated cloud deployment pipelines.

## 🔗 Live API Deployment
* **Base URL:** `https://onrender.com`
* **GET Endpoint:** `https://onrender.com/get`
* **Interactive Docs UI:** `https://onrender.com/docs`

---

## 🛠️ Architecture & Tech Stack
* **Framework:** FastAPI (Asynchronous Server Gateway Interface)
* **Data Validation:** Pydantic (Strict typing via schemas Engine)
* **Server Runtime:** Uvicorn (High-performance ASGI server compliance)
* **Middleware:** CORS (Cross-Origin Resource Sharing initialized for universal frontend access)
* **Deployment Infrastructure:** Git, GitHub API hooks, and Render Web Services cloud pipeline
